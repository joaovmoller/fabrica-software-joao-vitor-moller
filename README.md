# Landing Page - Panorama do Mercado Tech
## Descrição
Este projeto é uma landing page acadêmica desenvolvida para apresentar
um panorama inicial do mercado de tecnologia.
## Tecnologias utilizadas
- HTML5
- CSS3
- Bootstrap 5
- Git
- GitHub
- GitHub Pages
## Como executar
Abra o arquivo index.html no navegador ou utilize a extensão Live Server.
